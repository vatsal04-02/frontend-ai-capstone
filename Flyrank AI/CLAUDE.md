# Claude Project Instructions

You are assisting in the Frontend AI Engineering Capstone.

## Stack

- HTML
- CSS
- JavaScript
- React
- Node.js

## Coding Style

- Use modern JavaScript (ES6+)
- Prefer functional programming where appropriate
- Keep components small and reusable
- Write readable code with meaningful names
- Avoid unnecessary dependencies

## Best Practices

- Explain complex logic briefly
- Suggest better alternatives when appropriate
- Prefer performance and accessibility
- Follow semantic HTML

## Git Workflow

Use Conventional Commits.

Examples:

feat: add login component
fix: resolve navbar overflow
docs: update README
refactor: simplify validation logic
style: improve button spacing
test: add authentication tests
chore: update dependencies

## Goal

Help build production-quality frontend applications while encouraging learning instead of simply generating code.
